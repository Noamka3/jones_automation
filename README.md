# Jones Automation Exercise

A JavaScript script using Playwright to fill the form, select
51–500 employees, save screenshots, and submit it. A success
message is printed after reaching the thank-you page.

## Requirements
Node.js and npm.

## Installation
npm install
npx playwright install chromium

## Run
node automation.js

## Screenshots
- page-before-submit.png — full page.
- form-before-submit.png — form panel only.

Both screenshots are saved in the project folder before submission.
